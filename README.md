# PixelGallery

A modern, responsive image gallery built with HTML, CSS, and JavaScript.

## Features
- 50 images in a responsive grid
- Category-based image filtering
- Interactive lightbox with next/previous navigation
- Keyboard controls
- Smooth hover effects and transitions
- Responsive design for desktop, tablet, and mobile

## Tech Stack
- HTML5
- CSS3
- JavaScript
- [Picsum Photos](https://picsum.photos/) for images
