# PixelGallery

A modern, responsive image gallery built using HTML, CSS, and JavaScript. Explore a collection of 50 images with category filtering, smooth hover effects, and an interactive lightbox experience.

## ✨ Features

- **50 Images:** Display a collection of images in a clean, organized grid.
- **Responsive Layout:** Five columns on desktop, adapting to smaller screens.
- **Category Filters:** Filter images by Nature, Animals, Architecture, and Technology.
- **Lightbox Viewer:** Open images in an enlarged overlay.
- **Image Navigation:** Navigate between images using Next and Previous buttons.
- **Keyboard Support:** Use arrow keys to navigate and Escape to close the lightbox.
- **Smooth Animations:** Enjoy hover effects, transitions, and zoom animations.
- **Simple Interface:** Minimal design without unnecessary image labels.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Picsum Photos for remote image loading

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- An internet connection to load images
- A code editor such as Visual Studio Code (optional)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/PixelGallery.git
   ```

2. Open the project folder:

   ```bash
   cd PixelGallery
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code.

## 🎮 How to Use

1. Open the gallery to view all 50 images.
2. Select a category to filter the images.
3. Click an image to open the lightbox.
4. Use Next and Previous to navigate.
5. Press the left or right arrow key to change images.
6. Press Escape or click the close button to exit the lightbox.

## 📱 Responsive Design

The gallery adjusts its layout according to screen size:

- Desktop: 5 columns
- Smaller laptops: 4 columns
- Tablets: 3 columns
- Mobile devices: 2 columns

## 🌐 Image Source

Images are loaded from [Picsum Photos](https://picsum.photos/). An internet connection is required to display them.

The category labels are assigned in JavaScript for filtering purposes and do not guarantee that each photograph matches its category.
